# Idempotency Keys for PaymentIntent Creation

An idempotency key is a unique token generated by the client that Stripe uses to recognize retries of the exact same request. When creating stateful resources like PaymentIntents, network timeouts or connection drops can leave the client uncertain whether the request succeeded.

By including the Idempotency-Key header (such as a UUIDv4 or order-specific hash like order_4471_attempt_1), retrying the identical POST request will return the previously generated PaymentIntent object instead of creating an accidental duplicate charge. Idempotency keys are cached for 24 hours. For previously created duplicate PaymentIntents that resulted in accidental double charges, developers should retrieve the customer's recent charges and immediately refund the duplicate transaction.
